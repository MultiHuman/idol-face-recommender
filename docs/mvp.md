# MVP Spec

## 제품 한 줄 설명

좋아하는 아이돌 멤버 몇 명을 입력하면, 얼굴 임베딩 유사도를 기반으로 취향에 맞을 가능성이 높은 다른 멤버를 추천하는 로컬 프로그램.

## 문제 정의

사용자는 여러 아이돌 멤버 중에서 자신이 좋아하는 얼굴 취향의 공통점을 직접 설명하기 어렵다.  
이 프로젝트는 사용자가 고른 최애 멤버들의 얼굴 특징을 평균 벡터로 요약하고, 그와 비슷한 멤버를 자동으로 찾아준다.

## 목표

- 크롤링부터 추천까지 한 번에 이어지는 최소 파이프라인 구축
- 수치상 그럴듯한 추천 결과보다, 체감상 "어? 이 추천 재밌는데?"가 먼저 나오게 하기
- 확장 가능한 데이터 구조 확보

## 비목표

- 대규모 학습 모델 직접 훈련
- 실시간 배포 서비스
- 저작권이나 상업 서비스 대응
- 완벽한 얼굴 미학 분류기

## 사용자 흐름

1. 운영자는 멤버 목록을 준비한다.
2. 운영자는 멤버별 사진을 수집한다.
3. 시스템이 얼굴만 추출하고 임베딩 벡터를 생성한다.
4. 시스템이 멤버별 평균 벡터를 만든다.
5. 사용자가 좋아하는 멤버를 3~5명 선택한다.
6. 시스템이 추천 멤버 Top N을 보여준다.

## 핵심 알고리즘

### 입력

- 사용자가 선택한 멤버 ID 목록
- 멤버별 대표 벡터

### 처리

1. 선택된 멤버들의 대표 벡터 평균을 구한다.
2. 그 평균을 `taste_vector`로 사용한다.
3. 전체 멤버와 코사인 유사도를 계산한다.
4. 입력 멤버를 제외한 뒤 높은 순으로 정렬한다.

### 출력

- 추천 순위
- 멤버 이름
- 그룹명
- 유사도 점수
- 사용된 이미지 수

## 데이터 최소 기준

- 초기 대상: 20~30명
- 멤버당 유효 얼굴 이미지: 최소 8장, 권장 15장 이상
- 단체 사진보다 개인 사진 우선
- 흐리거나 가려진 얼굴은 제외

## 품질 규칙

- 가장 큰 얼굴 1개만 채택
- 얼굴 영역이 너무 작으면 폐기
- 같은 사진 중복은 제거
- 멤버당 유효 이미지 수가 `min_images`보다 적으면 추천 대상에서 제외

## 디렉터리 역할

- `data/raw_images/`: 원본 이미지 저장
- `data/face_crops/`: 얼굴 crop 결과 저장
- `data/embeddings/`: 임베딩 산출물 저장
- `data/image_embeddings.csv`: 이미지 단위 임베딩 메타데이터
- `data/member_vectors.csv`: 멤버 단위 평균 벡터

## 구현 순서

### 1단계

프로젝트 뼈대와 데이터 포맷을 고정한다.

완료 기준:
- 폴더 구조 생성
- CSV 템플릿 작성
- 추천 엔진 CLI 동작

### 2단계

크롤링 스크립트를 붙여 원본 이미지를 저장한다.

완료 기준:
- 멤버 목록 기반 검색 가능
- 멤버별 폴더에 이미지 저장
- 실패 로그 기록

### 3단계

얼굴 검출과 임베딩 추출을 구현한다.

완료 기준:
- 이미지마다 얼굴 검출 수행
- 유효 얼굴만 저장
- `image_embeddings.csv` 생성

### 4단계

멤버 벡터 집계와 UI를 완성한다.

완료 기준:
- `member_vectors.csv` 생성
- Streamlit 앱에서 최애 선택 가능
- 추천 결과 Top N 출력

## 성공 판단 기준

- 입력 멤버 3명을 넣었을 때 결과가 충분히 다양하게 나온다.
- 직관상 비슷한 인상이나 취향선이 어느 정도 보인다.
- 추천 결과가 완전히 랜덤처럼 느껴지지 않는다.
